# Data

The datasets are publicly available from Kaggle and are not redistributed in this repository. Download both, unzip them, and place the CSV files as follows:

```
data/
  twitter/Mental-Health-Twitter.csv                      # infamouscoder/mental-health-social-media (version 2)
  behaviour/digital_habits_vs_mental_health.csv          # abhishekdave9/digital-habits-vs-mental-health-dataset (version 2)
```

- Twitter corpus: <https://www.kaggle.com/datasets/infamouscoder/mental-health-social-media>
- Behavioural dataset (synthetic): <https://www.kaggle.com/datasets/abhishekdave9/digital-habits-vs-mental-health-dataset>

The analysis used the versions available on 2 October 2026.
